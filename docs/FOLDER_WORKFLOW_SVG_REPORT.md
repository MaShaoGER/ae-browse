## 界面

首次显示路径配置，载入后以素材网格为主。常驻来源切换、刷新、子目录筛选和搜索；添加、输入路径、参数图形包与移除位于“来源管理”。记住上次使用来源，无记录时优先普通文件夹。移除只删除登记。

中性深灰、24px 控件、细分隔线和蓝色选中态，读取 AE 深色面板背景并监听主题变化。宽面板默认给素材区约 64%，窄面板上下分区且省略重复的大预览，两种比例分别记忆。仍为 CEP 实现，未宣称使用 AE 原生控件。

## SVG

默认“可编辑形状图层”。CEP 对经过现有只读服务检查的 SVG 快照进行 DOM 解析，将常见路径、矩形/圆角、圆/椭圆、多边形、折线/直线、分组变换、视口缩放、纯色填充、描边及透明度转换为有界几何计划。多个 SVG 元素成为单层内的独立形状组；复合路径保留填充规则与孔洞。宿主校验尺寸、颜色、顶点、切线和复杂度后创建，并回读实际路径。

当前边界：渐变、文字、样式表、use、动态元素、裁剪/蒙版/滤镜、分组透明度、虚线、非等比变换的描边等明确拒绝。用户可手动选择“透明图片”，保留既有最高四倍/4096px 的图片通道。不会静默切换；源 SVG 不修改。SVG 形状可在 AE 中编辑，但不属于参数图形包实例，不能使用包实例的“更新所选图形”。

实际 AE 中修复：嵌套三元表达式在本机宿主选择了错误分支，改用显式 if/else；圆角转角下斜接限制为隐藏属性，仅斜接时写入；AE 形状组与 SVG 的绘制顺序相反，改为逆序创建。

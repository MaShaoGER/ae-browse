# 图形库接口边界测试报告

日期：2026-10-14（香港时间）。本报告区分文件/接口测试、AE 实际执行和渲染检查。

## 结论

文件式图形库、使用提示/错误提示和可选效果栈可以纳入首版协议。建议从一开始固定包身份、协议版本、相对资源路径、参数类型、依赖声明、稳定诊断代码和适配器入口。内容类型与特殊效果通过适配器扩展。

扩大接口并不等于第一版实现所有格式。当前项目是协议验证原型，不是已完成的 AE 浏览器。

## 场景与边界

| 场景 | 结果或建议策略 | 验证层级 |
| --- | --- | --- |
| 整包复制到新目录、中文与空格路径 | 相对路径仍可读取，内容指纹不随包目录变化 | 真实文件测试 |
| JSON 损坏、非法版本、重复素材 ID | 输出明确错误代码，阻止有歧义的包登记 | Node |
| 一项素材坏了或类型未知 | 隔离该项，其余正常素材仍可用 | Node |
| 缩略图缺失 | 提示并使用占位图 | Node 预检策略；界面未实现 |
| 源文件或必需资源缺失 | 停用该素材并提示补齐文件 | Node |
| 可选效果没安装 | 跳过该效果，标记降级 | 模拟宿主策略 |
| 必需效果没安装 | 阻止该素材添加 | 模拟宿主策略；AE 缺失效果检测也已实测 |
| 中英文效果名称不同 | 内部 matchName 用于匹配 | Node；中文 AE 实测 |
| 普通模糊/颜色参数 | 可添加和写入，并回读确认 | 实际 AE 与画面 |
| 曲线、插件自定义数据、特殊资源输入 | 需要专用适配器，通用入口不承诺完整复制 | 未实现的扩展边界 |
| 没打开合成、没选图层、图层锁定 | 浏览仍可用，执行时提示解决办法 | 模拟上下文策略 |
| 已有关键帧或表达式的参数 | 执行器必须选择保护/修改策略 | AE 实测静态 setValue 对关键帧会报错；表达式保护待实现 |
| 同一包重复复制或版本冲突 | 复用或要求选择，保留用户预设 | Node 登记决策；正式索引与更新未实现 |
| 包内路径指向外部或可执行脚本 | 拒绝该资源 | 真实文件与 Node |
| 1000 个素材条目 | 文件和结构预检完成，本次约 151 ms | Node 元数据预检，不能外推 AE UI/渲染性能 |
| 删除后的 Item ID 再查询 | 本机 itemByID 会抛异常，需保护查询或扫描确认 | 清理阶段实际发现并处理 |

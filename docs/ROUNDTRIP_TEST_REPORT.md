## 本轮修复

- 缺失可选缩略图曾使内容指纹计算失败；现在用确定标记继续计算，必需资源缺失仍报错。
- 修正了最低层目录错误直接抛异常，以及语义版本格式检查过宽的问题。
- 初次宿主执行中，嵌套条件表达式的动画分派没有定位到预期属性。改为明确 if/else，并验证实际 matchName，确认缩放、位置和透明度分别写入正确通道。
- 填充效果的颜色在实际属性树中是第 3 项，固定第 2 项验收读到了“所有蒙版”。效果写入和验收按内部属性路径进行。
- AE ES3 对保留字的限制需要真实编译验证；修正了 `native` 变量和未加引号的 `default` 字段。Node 能解析不代表 AE 一定能解析。
- 捕获关键帧、缓动、外观及效果属性状态，防止当前数值相同的手工关键帧被误判为未修改。
- 重复请求检查增加插入时间、素材身份、包版本和源内容；不同请求不能用同一操作 ID 静默复用。
- 二维尺寸绑定支持实际更新与回读。

失败的第一轮记录保存在 ae-roundtrip-first-attempt.json，不计入最终通过结果。后续修正后的执行、请求保护和像素证据分别保存，避免用旧记录冒充通过。

## 已确认的保护行为

- 无目标合成、非法参数、越界时长、缺失必需效果：创建图层前拒绝。
- 必需效果属性写入失败：清理本次刚创建的图层，不留下半成品。
- 可选效果缺失或参数失配：跳过/移除失败效果，保留基础图形并返回提示。
- 锁定图层、手工外观修改、外观关键帧、效果关键帧或缓动修改：停止自动更新或导出，保留原内容。
- 重复相同请求：复用实例；改变时间、版本、效果或参数：明确报告冲突。
- 已有导出文件：停止覆盖。
- 换合成尺寸与帧率：重新使用目标合成中心与相对插入时间。该用例检查数据定位，未声明所有帧率下逐像素完全一致。

## 清理与影响

本轮开始时 AE 是空工程。所有测试合成都已删除，并另外只读扫描确认，项目项数量恢复为 0，临时项目项剩余 0。未保存工程。测试创建/删除操作会进入 AE 撤销历史；不承诺撤销栈和 dirty 标志完全恢复。

图形包、渲染帧、报告和测试样例保留在项目 `test-results`，便于检查。它们是文件证据，不是 AE 中残留的测试合成。

## 当前实现边界

实现的是一个形状层、矩形和填充的最小适配器，包含无动画、缩放入场、滑入和淡入。基础效果的匹配、数值/颜色设置和导出已实际验证。

仍未实现完整浏览面板、原生选色交互、实时滚动与预览性能、任意路径/形状组合、预合成依赖收集、任意表达式及第三方效果自定义数据、ZIP 自动解压、完整包安装/升级，以及导出原子事务。外观更新入口不重写动画；修改动画会返回不支持的提示。

完整清单校验仍是 Node 实现；ES3 执行层在本轮 AE-MCP 环境运行，正式纯 JSX 发布还需 JSON 支持、加载器和相同强度的文件/链接校验。AE-MCP 用于测试，不是图形包的运行依赖。

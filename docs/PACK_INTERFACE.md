# 可复制图形包与扩展接口草案

状态：v0.1 设计与验证原型。清单规则和原生圆角卡片的最小生成、更新、基础效果、回读及导出已实现并验证；面板、通用生成器、预合成模板导入器和通用素材导出器尚未实现。详见本轮 ROUNDTRIP_TEST_REPORT.md。

## 1. 包的单位与传播方式

一个图形库是一个自包含文件夹，入口固定为 `pack.json`。最简结构如下：

```text
my-library/
  pack.json
  assets/
    rounded-card.json
  previews/              # 可选：PNG 缩略图或动画缓存
  resources/             # 可选：图片、视频等模板依赖
  LICENSE.txt            # 作者提供的传播约定
```

复制整个文件夹即可传播。可压成 ZIP 传给别人，首版由接收方解压后载入；纯 JSX 自动解压不是首版的必需能力。单文件封装可在后续包装层加入，不改变内部清单。

所有资源声明使用包内相对路径；载入时按包目录解析。禁止绝对路径、上级目录路径、指向包外的链接，以及有歧义的 Windows 文件名。中文名称和路径允许使用，稳定 ID 使用 ASCII 字母、数字、点、下划线和连字符。

模板 AEP 中实际引用的素材也必须收集并重定位到包内；仅仅把 AEP 文件复制进包，不足以证明模板已经自包含。字体和安装式效果插件作为环境依赖声明，不承诺随图形包自动安装。许可说明可携带，但工具不能自动判定所有资源的传播权利。

## 2. 固定协议，开放内容类型

- `schemaVersion`：清单协议版本。未知主版本明确拒绝读取。
- `pack.id`：稳定图形库 ID；移动文件夹不改变它。
- `pack.version`：内容语义版本，与清单协议版本分开。
- `asset.id`：包内唯一素材 ID。
- `asset.kind`：素材类型。已约定 `ae.nativeShape`、`ae.project`、`ae.ffx`、`ae.footage`；当前只是声明与预检入口，不表示四个执行适配器都已完成。
- `asset.source`、`resources`、`preview`：源文件、必需资源与可选预览。
- `parameters`、`effects`、`requirements`、`help`：可开放参数、效果栈、依赖与使用说明。
- `extensions`：按作者/厂商命名空间存放扩展信息。

新类型通过注册适配器增加。当前浏览器不认识某个类型时，显示其名称与缺失能力，停用该项；其他正常素材仍可使用。未知附加元数据保留，但不解释为可执行操作。

正式版本的稳定操作入口建议为：

| 操作 | 目的 | 对 AE 的影响 |
| --- | --- | --- |
| inspectPack / registerPack / listAssets | 检查、登记和浏览库 | 无 |
| preflightAsset | 检查执行能力、文件、效果及操作上下文 | 只读 |
| previewAsset | 简化预览、缓存预览或真实 AE 帧 | 分别标注；真实预览可能需要临时合成 |
| instantiateAsset | 添加新图形或模板实例 | 创建可追踪的项目项/图层 |
| updateInstance | 修改本工具生成且身份匹配的实例 | 受保护地更新 |
| applyEffects | 对明确指定的目标添加/更新效果栈 | 修改图层属性 |
| captureAsset / exportPack | 保存支持的参数、动画和依赖 | 先报告不支持或无法收集的内容 |

类型适配器统一实现 `inspect`、`validate`、`preflight`、`instantiate`；`capture`、`update`、`preview` 可按能力声明提供。效果适配器与素材类型适配器分开，避免增加一种效果就修改所有图形生成器。

## 3. 参数、状态与动画

基础参数类型：number、color（RGBA 四个 0–1 分量）、boolean、enum、text、point2。参数带稳定 ID、默认值、范围、单位和 help；枚举使用稳定值，显示文字可本地化。

状态保存参数快照；动画保存目标节点 ID、属性通道、插入时间原点、相对时间、关键帧及缓动。实际生成时统一处理当前合成位置、帧率、入点和时长，不保存固定的用户工程坐标。

尺寸、颜色和透明度可以做常规状态过渡。任意路径变形需要点数、顺序及切线对应策略；路径拓扑改变时，不默认复用旧动画。图层引用、字体、复杂表达式及插件自定义数据需要独立依赖检查或专用适配器。

最小计划编译器已验证圆角卡片所需的参数绑定、状态引用、动画目标与值维度；当前支持一个形状层、一个矩形及填充。路径、多组形状、嵌套预合成和通用动画图仍需要独立适配器。

## 4. 效果栈

每个效果包含实例 ID、内部 `matchName`、目标节点、是否必需以及参数设置。内部名称用于跨语言识别；同一种效果的多个实例使用不同 ID，顺序必须保留。

已在本机 AE 26.0 读写确认的高斯模糊参数声明示例：

```json
{
  "id": "soften",
  "matchName": "ADBE Gaussian Blur 2",
  "required": false,
  "target": "output",
  "settings": [
    {
      "path": [{ "matchName": "ADBE Gaussian Blur 2-0001", "occurrence": 1 }],
      "valueType": "number",
      "value": 12
    }
  ]
}
```

执行时先读取 `app.effects` 与 `canAddProperty`。添加效果会改变属性组，随后必须重新取得属性引用，再写入并回读确认。

- 缺失必需效果：阻止该素材实例化。
- 缺失可选效果：提示并跳过，结果标为降级。
- 属性路径不存在、值类型不支持、效果版本不兼容：报告具体效果和参数，不猜测其他字段。
- 第三方效果可挂接，但只对经过验证的基础属性提供通用写入。曲线编辑器、自定义 blob、特殊资源加载及许可相关交互需要专用适配器。
- FFX 可以是包内素材；保存任意选中效果为 FFX 的完整自动导出流程尚未实现，不把图形参数 JSON 导出等同于 FFX 导出。

## 5. 使用提示与报错接口

使用提示显示在操作前：需要打开合成、选中图层、依赖什么效果或字体、哪些参数可修改。无需每次弹窗。

诊断数据包含：`code`、`severity`、`phase`、`scope`、`assetId`、`pointer`、`message`、`actions`。现有校验器已经返回这些字段。正式面板将 actions 转为有稳定动作 ID 的按钮，日志保存原始技术信息，正常界面显示中文原因和解决办法。

```json
{
  "code": "E_NO_SELECTION",
  "severity": "error",
  "phase": "context",
  "scope": "asset",
  "assetId": "rounded-card",
  "message": "请先选择要添加效果的图层。",
  "actions": ["选择目标图层"]
}
```

全局协议/包身份错误阻止登记；单素材错误只隔离该项；预览缺失使用占位图；未连接 AE 可浏览但不宣称执行检查已通过。`canImport` 仅表示满足此原型的预检，不能证明完整执行适配器或渲染已实现。

## 6. 登记、更新、保护与失败清理

相同包 ID、版本和内容指纹可复用；同版本不同内容或不同版本都提示用户选择，不静默覆盖。用户自建预设存放在独立用户目录，引用包 ID/素材 ID，避免随包升级被替换。

当前指纹函数已对缺失的可选预览使用确定标记；缺失必需资源仍失败，包外资源仍拒绝。正式登记的目录索引、包安装与更新还需要原子写入流程。

最小实例的重复请求检查同时比较包/素材身份、版本、源内容、参数及插入时间；相同操作 ID 的不同请求会报告冲突，避免误复用旧实例。

更新实例只操作本工具记录的稳定 ID。手工修改、关键帧、表达式、锁定图层都要有明确策略；默认避免覆盖不认识的内容。

Undo 分组不等于事务回滚。正式执行器应预检后再写入，记录本次创建的对象，失败时清理自己创建的对象；更新已有图层则需保存旧值或让用户明确撤销。对删除后的 ID 查询也要捕获异常。

## 7. 性能预算与边界

当前临时预算：清单和 JSON 图形描述各 4 MiB、每包 5000 素材、数据深度 64、单字符串 16384 字符。预算可配置，用于限制一次解析工作；这些数值不是 AE 实际性能上限。

浏览与缩略图缓存应按需加载；批量操作分批执行，动画图和效果参数按需展开。解析后还需要图形复杂度、图层数量、效果成本和取消操作的执行预算。文件大小检查、路径检查和类型检查不等于认证渲染性能。

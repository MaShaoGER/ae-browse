# CEP 开发构建与安装

日期：2026-10-14（香港时间）。版本：0.2.0。目标：Windows、AE 26、CEP 12；目标范围不是实测兼容性声明。

最新实测：AE 26.0x67、CEP 12.0.1、内置 Node 17.7.2 的基础加载、库登记和面板导入闭环通过。开发扩展现已安装；本页安装命令供其他环境参考，当前机器不要重复覆盖。完整结果见 [实机报告](CEP_LIVE_TEST_REPORT.md)。

## 构建

```powershell
cd D:\project\ae-browse
node scripts/build-cep.cjs
```

输出 `dist/AE Browse/`，包含根 `CSXS/manifest.xml`、`cep/` 界面与 Node 服务、共享 `src/`、合并后的 `jsx/host.jsx` 和内容指纹清单 `build-info.json`。固定官方 CSInterface 与附带许可证已纳入源码，构建不下载运行依赖。测试样例和帧文件不进入扩展。

JSX 按 JSON 编解码器 → 计划编译器 → 原生执行层 → 分发入口顺序合并。宿主入口不读取图形包路径，Node 将经过校验的所选素材快照发送给宿主。运行不依赖系统 Node 或 MCP。

## 开发安装

构建本身不会安装扩展或设置注册表。以下是首次安装命令；当前机器已有开发扩展，无需重复运行：

```powershell
.\scripts\install-dev.ps1
```

脚本复制开发产物到 `%APPDATA%\Adobe\CEP\extensions\local.aebrowse`；目标已存在时停止，不覆盖旧扩展。重新打开 AE，在“窗口 → 扩展”菜单查找 AE Browse，具体菜单名称以 AE 界面为准。

未签名的开发扩展需要对应 CEP 的调试配置。若已确认使用 CEP 12，需要时可运行：

```powershell
.\scripts\install-dev.ps1 -EnableDebug
```

该开关除了复制扩展，还会将 `HKCU\Software\Adobe\CSXS.12\PlayerDebugMode` 设置为字符串 `1`，允许加载未签名扩展。若目标已存在，脚本先停止，不会设置调试开关。正式签名包的安装不应依赖开发调试模式；正式 ZXP 尚未制作。

官方参考：[Adobe CEP 12 开发与调试](https://github.com/Adobe-CEP/CEP-Resources/blob/master/CEP_12.x/Documentation/CEP%2012%20HTML%20Extension%20Cookbook.md)。实际 CEP、Chromium、Node 版本需要在实际面板中确认，不能用系统 Node 代替。页脚目前显示 Node/Chromium，宿主版本通过固定 JSON 桥读取。

## 使用流程

1. 添加含 `pack.json` 的图形库文件夹；对话框不可用时可输入完整目录。示例：`D:\project\ae-browse\examples\portable-demo`。
2. 搜索名称或标签，查看素材诊断、参数和使用提示。错误素材显示原因，正常素材继续可用。
3. 在 AE 打开目标合成，点击“刷新合成”。调整宽度、高度、圆角、颜色、动画和时长。
4. 点击“添加到当前合成”。面板重新读取实际合成、检查库指纹与参数，再发送请求；执行层再次确认目标身份，创建后回读。

没有合成时仍可浏览。相同包 ID/版本但内容不同，或同 ID 的新版本，不直接覆盖登记；先移除旧登记，再明确添加选择的版本。源目录移动后可以添加内容相同的新目录，复用身份并更新位置。

颜色目前使用面板选色器和预览色块，尚未接入 AE 原生选色。近似预览只画基础卡片，不预览效果栈和真实动画。网格每批显示最多 100 项，可点“继续显示”；这不是虚拟滚动或 5000 素材性能认证。

## 文件与错误状态

登记位于 `%APPDATA%/AE Browse/libraries.json`，恢复副本为 `libraries.backup.json`。写入先在同目录暂存、同步和重命名；来源目录不写入设置。来源丢失显示不可用，登记保留，源文件不会被删除。

新库登记与刷新捕获有界字节快照；搜索只读缓存。单文件当前最多 16 MiB，包内快照合计最多 64 MiB，JSON 描述/清单继续遵循原协议 4 MiB 预算；超过范围给诊断。首次登记和刷新尚无大库性能验收。

AE 请求串行执行。超时只代表尚未收到返回，不代表 AE 停止；按钮保持锁定，不自动重发创建请求。收到有效迟到结果后恢复。协议损坏或没有任何返回时保留待确认状态，需要检查 AE 中的结果，不应借重新打开面板盲目重试。

# 文件夹与文件拖入

2026-10-18，0.2.0 开发版。

从 Windows 资源管理器拖入普通文件夹或多个 SVG、PNG、JPG/JPEG 文件。拖入时显示接收提示；松开后登记到面板，随后选择素材并点击“添加到当前合成”。不在拖入时直接操作 AE 图层。

文件夹复用原有递归扫描。零散文件按原始父目录分别登记，持久化在 folders.json 的可选 files 列表中，只读取明确选择的文件，不顺带登记同目录其他素材。重复拖入同目录会合并文件列表；目录登记与散文件登记互相独立。源文件只读，原有内容指纹、SVG 检查、导入缓存与变化检测继续生效。

接收阶段同步捕获 CEP File.path，交由 Node 检查真实本地路径和文件类型。缺少路径时给出“添加文件夹/输入路径”替代入口，不凭文件名猜测绝对路径。不接收网页 URL、文本、链接或不支持的文件类型。每次最多拖入 1000 项；沿用原有扫描和单文件预算。忙碌、未确认的宿主结果及浏览器演示状态禁止登记；重复快速拖入不会并发提交。
